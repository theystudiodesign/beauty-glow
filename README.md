## Publish on GitHub Pages
1. github.com → New repository → name: beauty-glow → Public → Create.
2. "uploading an existing file" → drag index.html + the assets folder → Commit.
3. Settings → Pages → Branch: main / root → Save.
4. After 1-2 min the site is live at: https://USERNAME.github.io/beauty-glow/
